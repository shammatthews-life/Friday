# LICENSE NOTES

This project is for local research and prototype development in assistive vision systems.

## Safety and scope

- This is not a certified mobility aid.
- Monocular depth is estimated and approximate.
- Do not claim safe autonomous guidance or replacement for a cane, guide dog, or trained mobility aid.
- Safety logic must remain conservative and independent from any optional language model.

## Model and dependency licensing

- Validate the license of each model and dependency before distribution or broader deployment.
- Use official sources and model cards.
- Check AGPL/other terms if redistributing or shipping binaries.

## Research status

This repository is a local prototype foundation for FRIDAY and VisionAid. It is not production-grade assistive navigation software.
