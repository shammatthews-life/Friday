# VISIONAID / FRIDAY

Local desktop AI assistant for assistive vision research.

This repository is the Phase 0 foundation for FRIDAY: a modular local AI assistant running on a Windows PC with a webcam, microphone, speakers, and local inference.

## Scope

- Local-only model execution
- No cloud APIs
- Deterministic scene reasoning before optional language model use
- Safety-first design
- Benchmarking before model selection

## Project status

Phase 0 complete: machine audit, environment setup, project scaffold, and model registry foundation.
